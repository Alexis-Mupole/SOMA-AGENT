# Soma-Agent: Ugandan O-Level Educational Hub

Soma-Agent is a high-fidelity, AI-powered educational orchestrator specifically tailored for the **Ugandan NCDC O-Level Syllabus**. It provides a centralized ecosystem for Students, Teachers, Parents, Academics (Directors of Studies), and System Administrators to collaborate and track academic mastery.

## 🚀 Key Features

### 👨‍🎓 Student Portal
- **Syllabus Mastery Map**: Visual progression through NCDC units (Biology, Math, Physics, Chemistry).
- **AI Study Specialist**: A Gemini-powered tutor (Soma-Agent) that provides syllabus-aligned explanations and motivational Ugandan proverbs.
- **Daily Drills**: Interactive quizzes generated from teacher-uploaded resources.
- **Academic Guidance**: Direct feedback loop from teaching specialists.

### 👩‍🏫 Teacher Dashboard
- **Resource Hub**: Upload and publish lesson notes and curriculum materials.
- **Class Progress Tracking**: Real-time analytics on student mastery and engagement.
- **Assessment Management**: Schedule and notify classes of upcoming termly exams and unit tests.

### 🏡 Parent Hub
- **Soma-Code Linking**: Securely link to a student's profile to track their progress.
- **Mastery Analytics**: High-level view of subject-specific performance and study time.
- **WhatsApp Integration**: Celebratory progress sharing.

### 📋 Academic (DOS) Console
- **Enrollment Queue**: Manage and approve new student account registrations.
- **Classroom Deployment**: Create and organize school classes (e.g., Senior 4 North).
- **Staffing Assignments**: Link teaching specialists to specific curriculum subjects.

### 🛡️ Admin Mission Control
- **Global Infrastructure**: Monitor system health, API latency, and traffic.
- **User Directory**: Full authority management over all institutional profiles.
- **System Configuration**: Real-time control over AI cognitive engines and maintenance modes.

## 🛠️ Technology Stack
- **Frontend**: React (ES6 Modules), Tailwind CSS (Institutional UI/UX).
- **AI Cognitive Engine**: Google Gemini API (`gemini-3-flash-preview` for efficiency, `gemini-3-pro-preview` for deep reasoning).
- **Data Visualization**: Recharts (High-density analytical dashboards).
- **Database Architecture**: Supabase (PostgreSQL with Row Level Security).

## 🇺🇬 Institutional Context
Designed to embody the spirit of Ugandan excellence, featuring themes inspired by national identity (Crane Yellow, Uni Blue, Leaf Green) and supporting schools like **Gayaza High School** with high-fidelity digital infrastructure.
